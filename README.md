# Car Dealership System

A complete car dealership system for FiveM servers.

## Features

- Buy and sell cars with the dealership
- View your car inventory
- Customizable dealership location and prices

## Requirements

- FiveM server
- ESX Framework
- MySQL

## Installation

1. Download the script
2. Place the script in your FiveM server's resources folder
3. Add `start car_dealership_tycoon` to your server.cfg
4. Import the database.sql file into your MySQL database

## Usage

- Players can access the dealership by approaching the dealership marker
- Use the menu to buy, sell, or view your car inventory

## Configuration

The script can be configured in the `config.lua` file. You can change the dealership name, location, car prices, and more.
